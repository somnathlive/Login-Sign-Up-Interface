# Modern Login & Sign-Up Interface

A sleek, responsive, and modern dual-card Authentication UI built with pure **HTML5**, custom **CSS3** (incorporating modern gradients, subtle glassmorphism-inspired borders, and smooth transitions), and interactive **JavaScript**.

##  Features

* **Dual-Card Toggle:** Seamless, lightweight JavaScript logic that toggles between the Login and Sign-Up cards dynamically without page reloads.
* **Modern Aesthetic:** Crafted with crisp typography (Inter), custom radial-gradient backdrops, soft box-shadow depths, and responsive card layouts.
* **Interactive Elements:** Includes hover states, dynamic input focus rings, icon wrappers via **Font Awesome**, and form submission handlers with validation alerts.
* **Social Authentication Buttons:** Pre-styled placeholders for Google and GitHub sign-in options.
* **Fully Responsive:** Adapts fluidly across all devices, from large desktop monitors down to mobile viewports.

---

##  Built With

* **HTML5** – Semantic document structure.
* **CSS3** – Flexbox layout, CSS variables, gradients, transitions, and media queries.
* **JavaScript (ES6)** – DOM manipulation and card view toggling.
* **Font Awesome** – Vector iconography.
